# Ideas de proyecto

## Idea 1 — U-Track Raul Esteban Totaitive Beltran
U-Track es tu asistente académico personal. Organiza tus materias, tareas y exámenes en un solo lugar, recibe recordatorios antes de cada entrega y calcula la nota que necesitas para pasar cada materia. Nunca más un trabajo entregado tarde.

Aplicaciones similares:
- [myHomework Student Planner](https://play.google.com/store/apps/details?id=com.myhomework&hl=es&pli=1)
- [Timetable: Simple & Colorful](https://play.google.com/store/apps/details?id=com.everystudio.timetable&hl=es)

## Idea 2 — DailyCode Andres Santiago Zipa Marin 
App tipo Duolingo para aprender lógica de programación y Python desde cero, mediante lecciones cortas y gamificadas. Incluye sistema de experiencia (XP), vidas (corazones) y rachas diarias. Los ejercicios son interactivos (completar código, ordenar bloques, opción múltiple) y el progreso del usuario se guarda de forma local, sincronizándose automáticamente cuando hay conexión a internet.

Aplicaciones similares:
- [Mimo](https://play.google.com/store/apps/details?id=com.getmimo&hl=es)
- [Sololearn](https://www.sololearn.com/es/)
- [Duolingo](https://es.duolingo.com/)

## Idea 3 — Sistema de facturación Yoseph Felipe Galvis Gitan
La aplicación es destinada para los comerciantes que quieran una app con una interfaz fácil de usar para manejar su inventario y llevar a cabo la facturación legal que corresponde al país local.

Aplicaciones similares:
- [Stock Inventario Simple: StoDo](https://play.google.com/store/apps/details?id=com.stockmanagment.next.app&pcampaignid=web_share)
