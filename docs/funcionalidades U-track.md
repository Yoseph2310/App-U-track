# Funcionalidades de U-track

La siguientes es una lista de las funcionalidades disponibles para el usuario de la aplicación:

1. Crear una cuenta de usuario
  -El estudiante podrá registrarse y crear su propio perfil dentro de U-Track.
  -Podrá iniciar sesión para acceder a su información académica.
2. Registrar materias
  -El estudiante podrá agregar las materias que está cursando.
  -Podrá guardar información básica de cada materia, como nombre, profesor y grupo.
3. Registrar notas
  -El estudiante podrá ingresar las notas obtenidas en cada actividad.
  -Podrá registrar el porcentaje correspondiente a cada nota dentro de la materia.
4. Calcular la nota final
  -La aplicación calculará automáticamente la nota acumulada o final de una materia teniendo en cuenta los porcentajes de cada actividad.
  -También podrá mostrar cuánto necesita el estudiante en las actividades pendientes para alcanzar una determinada nota.
5. Calculadora de notas  
  -U-Track contará con una calculadora independiente para realizar cálculos de notas.
  -Esta herramienta podrá utilizarse para calcular notas propias o hacer cálculos para compañeros, sin modificar la información registrada en la cuenta del estudiante.
6. Registrar trabajos y actividades
  -El estudiante podrá registrar trabajos, talleres, proyectos y otras actividades académicas.
  -Podrá indicar la fecha límite y la materia a la que pertenece cada actividad.
7. Recordatorios
  -La aplicación enviará recordatorios sobre trabajos, exámenes y actividades próximas a vencer.
  -El estudiante podrá mantenerse informado sobre sus compromisos académicos.
8. Visualizar próximas actividades
  -El estudiante podrá consultar rápidamente qué trabajos, exámenes o entregas tiene próximos.
  -La información podrá organizarse por fecha o por materia.
Consultar el estado académico
El estudiante podrá visualizar de manera sencilla sus notas y el progreso de cada materia.
Esto le permitirá identificar en qué materias necesita prestar mayor atención.
